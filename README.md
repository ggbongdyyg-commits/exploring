# 88keys countdown

移动端优先的静态页面：弧形倒计时（44 → 00）+ 真实 88 键钢琴。系统按北京时间判断上午或下午，用户打开时小人跳到对应的键；中间隔了几天，就从上次停的键一键一键跳到当前。每次打开先选一个当下的心情，右上角随时可以回看。无后端，无依赖。

## 本地运行

需要 Node 18+。

```
npm run dev       # http://localhost:5173/ ，直接服务 src/
npm run build     # 复制 src 到 dist，去掉调试代码，并对所有模块做语法检查
npm run preview   # http://localhost:5173/ ，服务 dist/
npm test          # 键号、补跳、存储、周历、表情的断言
```

用手机浏览器或 Chrome 开发者工具的手机模式预览，竖屏。

## 部署到 Netlify

仓库根目录已有 `netlify.toml`：构建命令 `node scripts/build.mjs`，发布目录 `dist`。也可直接把 `dist/` 拖进 Netlify。

## 调试模式

只在本地 `npm run dev` 下可用，地址后加 `?dev`（或 `#dev`）。面板里可以：

- 拖动日期滑条（开始前 → 11/06 → 12/19 → 12/20 → 之后），或用 ±1 日
- 切换时段：上午 8:00、下午 15:00
- 往后拖日期会触发真实的补跳：先弹心情面板，选完后小人逐键跳到当前键。用来测试「隔几天再打开」
- 「自动走完 88 键」：每个时段随机选一个心情，走真实流程，跑完 44 天、88 个键
- 「瞬间填满」填随机心情并直接到第 88 键，用来看回看页；「重置」回到起点

调试模式使用内存存储和模拟时钟，不读写 localStorage。`npm run build` 生成的 `dist/` 不含调试代码，`?dev` 无效，线上用户无法改时间。

## 数据存储

- 存在浏览器 localStorage，键名 `88keys:v2`，格式 `{ v: 2, moods: { "YYYY-MM-DD": { am: { m: 表情id, t: 时间戳 }, pm: { ... } } }, seen: 小人上次站到的键号, reviewed: 是否已展开过结束回看 }`。
- 旧的 `88keys:v1`（早晚打卡时间戳）语义已作废，不迁移也不删除，直接忽略。
- 只在同一台手机、同一个浏览器、同一个网址下有效。换设备、清除站点数据、无痕模式关闭后，记录都会丢失。
- 日期和时段按北京时间（UTC+8）计算，与设备时区无关。

## 规则常量

`src/config.js`：起始日 2026-11-06、总天数 44、上午/下午分界 12:00、跳步与滚动时长、补跳总时长 4.5 秒。

- 第 d 天（从 0 起）上午对应第 2d+1 键，下午对应第 2d+2 键；开始前为 0，12/20 及以后为 88。
- 每次打开，若小人所在键低于当前键，且仍在 44 天内，先弹心情面板（可跳过），再逐键补跳。12/20 及以后不弹面板，自动走完并展开一次回看页。
- 同一时段选过或跳过后不再弹出；右下角圆形按钮显示该时段的表情，点它可改选，不触发跳键。
- 心情面板和回看页都不带文字标签，表情的中文名只用于读屏（aria）。跳过链接文案「先不说啦」，改选时「就这样吧」。

## 往回拨看过去的心情

- 用手上下拨圆环（拖动区域覆盖圆环一带）：手指往上推，数字变大，回到更早的日子；不能拨到「现在」之后，到头只有一点弹性，松手回弹。
- 回看时，琴键轨道滑到那天下午对应的键，右下角原本的按钮换成当天上午、下午两个表情（没记的显示虚线空环）。
- 回看只改变画面，不改小人真正所在的键，也不改存档。
- 回到现在：往下拨回去，或到了新的半天（自动回到现在并按需弹心情面板）。
- 补跳、选心情面板、回看页打开时，拨动不生效。

## 改选心情

- 回看页选中某一天后，下方的上午、下午表情可以点，弹出「想换一个心情吗？」改选；没记过的空环也能补记。
- 往回拨时，右下角的两个表情同样可以点，改选那一天对应时段。
- 只能改选已经到来的时段，未来的不行。

## 声音

每跳到一个键，在落地时合成该键的钢琴音（第 1 键 A0 = 27.5Hz，第 49 键 = 440Hz），不依赖音频文件。浏览器要求先有一次点按才能出声；iPhone 的静音拨片会让它无声。没有静音开关。

## 手写便签

回看页下方的便签使用凌慧体-简（Apple 系统字体）的子集 `src/fonts/handnote.woff2`，只含便签里的字。重新生成：

```
UV_CACHE_DIR=/tmp/bead-uv-cache uv run --with fonttools --with brotli python -I scripts/subset-font.py <LingWaiSC-Medium.otf> src/fonts/handnote.woff2 "<便签文字>"
```

该字体是 Apple 的系统资产，公开发布前请确认授权，或换成可商用字体。
