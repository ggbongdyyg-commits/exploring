# 倒计时

多个目标并行的倒计时，每天顺手记一个心情。纯 HTML/CSS/ES 模块，无依赖，可作为 H5 页面放进小程序 web-view。

## 运行

- `npm run dev`：本地服务 `src/`，地址 http://localhost:5173/（只监听 127.0.0.1）。
- `npm run build`：生成 `dist/`，去掉调试面板和 `dev.js`，并对所有 JS 做语法检查。
- `npm run preview`：服务 `dist/`。
- `npm test`：时间、模型、存储的单元测试。

## 调试

只在本地给地址加 `?dev`：出现底部面板，可日期 ±1/+7 天、回到今天、填充示例数据、清空。调试模式用内存存储，刷新即清；加 `&persist` 才写 localStorage。正式构建里 `DEV` 被固定为 `false`，`?dev` 无效。

## 规则

- 时区固定北京时间（UTC+8），日序号为自 1970-01-01 起的天数。
- 目标只需要名称和日期；开始日为创建当天，之后不变。
- 心情按项目、按天记录一条。打开某个项目的详情页，若当天没记也没跳过，就弹出 9 选 1 面板。
- 滚轮不可拖动，只在进入详情页和跨天时转动。
- 目标日当天首次进入详情页，自动展开一次心情回看。
- 改名称或日期不会清空已记的心情；删除项目会一并删除其心情。

## 存储

localStorage 键 `countdown:v1`：`{ v, items, moods, asked, reviewed, shown }`。存储集中在 `src/store.js`，接口不变的前提下可整体换成云端实现。

## 嵌入小程序

- 路由用 hash（`#/` 列表，`#/c/<id>` 详情），原生返回键走浏览器历史，可直接使用。
- web-view 需要 HTTPS 域名并加入小程序后台的业务域名白名单。
- 所有资源为相对路径，无第三方域名。
- web-view 里的 localStorage 可能被系统清理，正式使用建议改为云端存储。

## 目录

`src/` 页面与逻辑；`scripts/` 服务、构建、测试、截图；`mockups/` 已确认的视觉稿。
